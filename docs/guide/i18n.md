# 国际化

## 配置

```typescript
deer({
  config: {
    i18n: {
      locale: 'zh-CN',
      fallbackLocale: 'en-US',
      messages: {
        'zh-CN': {
          message: { hello: '你好' },
        },
        'en-US': {
          message: { hello: 'Hello' },
        },
      },
    },
  },
})
```

## 使用

```vue
<template>
  <div>{{ $t('message.hello') }}</div>
</template>

<script setup>
import { useI18n } from 'vue-i18n';
const { t } = useI18n();
console.log(t('message.hello'));
</script>
```

## UI 组件层

kangaroo-mobile 的组件也支持国际化，自动与框架层同步语言设置。
